正式第三版 **1.2.0（versionCode 42）**，采用已确认的 rc21 功能，最低 Android 10。沿用原签名，覆盖更新保留已有设置与记录。相对第二版的变化见 [第三版说明](docs/releases/1.2.0.md)，当前交付见 [最新版](docs/CURRENT_VERSION.md)。

新增动态图集识别与单项保存、视频／图集 GIF 制作、真实动态素材与 BGM 合成。原生 GIF／WebP 保留原格式，视频型动图保存为无声 MP4。GIF 可选分享或清晰参数，时长输入精确到 0.1 秒；静图序列支持每张 0.1 秒。自动读取失败时保留已有结果，可手动重试。

本版移除实况照片保存与动图转实况，动态卡片保留原素材／GIF 两类操作。旧记录不删除；普通视频、批量、天蓝主题、调色盘、图片背景、路径及历史功能继续保留。实际验证范围与限制见 [验证记录](docs/VALIDATION.md)。

## 可以做什么

- **保存视频与图集**：粘贴分享文案或链接，解析、预览并保存；图集可保存原图，读取到可用 BGM 后可在手机上合成 MP4。
- **制作 GIF 与动态 BGM 视频（第三版候选）**：选择分享或清晰 GIF，视频截取精确到 0.1 秒，最长可到视频结尾；多张静图可切换生成一个 GIF。动态素材与 BGM 合成保留实际运动；每项自动采用原时长，或输入 0.1–120 秒，截取与循环前确认。
- **直接保存作品**：下载与预览统一使用同一作品的无水印来源，无需选择版本；无法获取可用来源时会提示失败。
- **舒适地预览视频**：画面按原比例显示，播放条跟随主题色，支持拖动进度、静音和放大画面；前进、后退秒数可分别输入，下方一行 5／10／15／30／60 秒快捷值同时调整两侧。普通宽度尽量完整显示，窄屏或大字模式可横向滚动。
- **保持页面清爽**：一个按钮完成粘贴解析，输入框一键清空，旧解析结果随输入变化一起清除；各处输入框采用一致的圆角。
- **管理下载**：独立下载记录、搜索排序、重复下载提示，以及自定义文件名和保存文件夹。
- **一次解析整个队列**：首页集中展示所有结果，图集和失败项不阻塞后续任务；支持一键保存、长按拖动排序、上下移及左右滑动移除。处理结束或暂停后可清空全部任务，保留已下载文件和记录。
- **选择喜欢的颜色**：天蓝主题、浅色与深色模式、自选调色盘，选择后即时生效；外观滑块使用圆形滑钮和细轨道，直接查看真实页面效果。
- **让背景融入页面**：导入图片，调整裁切、虚化与暗度；完整显示时可选择位置，铺满裁剪时居中。板块不透明度支持 0–100%，文字保护可独立调节。

解析、下载与图集视频合成都在手机执行，不调用第三方解析网站或远程合成服务。下载和合成时使用前台服务显示进度。

## 开始使用

1. 在 [Releases](https://github.com/fanyinmo/yingxia/releases) 下载正式版 `yingxia-1.1.0.apk`，可覆盖首版或更早候选；已安装 1.2.0 候选时请继续使用对应候选包。
2. 在抖音复制作品分享链接，回到首页点击“粘贴并解析”。
3. 解析完成后直接下载视频、保存图片，或在有可用 BGM 时合成图集视频。

保存文件夹、主题和背景都在“设置”中调整。完整操作见 [安装与使用](docs/INSTALL.md)。

## 第二版有哪些变化

正式第二版 **1.1.0** 相对于首个 Git 版本 **1.0.0**，主要改进批量队列、预览播放器和解析链路：队列连续解析并集中显示结果，支持长按排序、滑动移除和清空；视频预览保持原比例，增加主题色进度条和可分别设置的前进／后退秒数；媒体确认找到第一个有效地址即停止，下载失败时使用同类备用来源。

主题调色盘、背景图片、图集下载与静图 BGM 合成是首版已有能力，第二版调整外观控件与来源兼容。图集展示图片不再要求同时存在明确水印下载变体，单条与批量规则一致，保留图片顺序与可用 BGM；第三版候选增加分类型保存与真实动态合成。完整差异见 [变更记录](docs/CHANGELOG.md)。

## 从源码构建

使用 **JDK 17、Android SDK 35**，在 Android Studio 中打开项目并同步。Windows 也可在仓库根目录执行：

```powershell
./scripts/build.ps1 -Validate
node --test parser-lab/browser-script.test.cjs parser-lab/public-page-script.test.cjs parser-lab/desktop-album-script.test.cjs
```

脚本按源码中的版本配置命名 APK；当前正式版本生成 `outputs/apk/yingxia-1.2.0.apk`，`v1.1.0` 标签源码生成正式版 `yingxia-1.1.0.apk`。Linux/macOS 可使用仓库自带的 Gradle Wrapper；环境配置与运行测试见 [构建说明](docs/BUILD.md)。

## 解析范围

影匣读取平台提供的公开作品数据。页面未提供数据、作品失效或接口拒绝访问时，解析可能失败；不会自动登录或自动处理验证码。自动读取图集遇到实际验证门槛时保留现有图片与重试入口，可由用户打开官方页面手动完成后继续读取；常驻登录按钮不作为验证门槛。下载与预览只使用同一作品的无水印播放或图片来源；缺少可确认来源时提示不可用。作者已经放进原画面的文字、标志等会保留。

媒体校验找到第一个有效来源后即停止，来源失败才继续尝试同类备用地址。解析耗时仍取决于网络和平台响应。升级后不再使用旧版的版本选择设置，原有下载记录和文件保留。

第二版已修复此前视频跳转到 `bdcgslb.com` 动态子域被拒绝的问题，后续候选补充严格数字冷 CDN 来源及安全分段传输。rc11 增加同作品官方播放入口的备用来源与受限桌面视频读取；“小咕嘎成为大学宿管”已在 MuMu 完整保存，实际成功路径为移动来源备用与重试，未据此宣称桌面 fallback 的真实网络验收通过。所有跳转继续检查 HTTPS、域名、端口和作品归属，完整签名地址和 Cookie 脱敏。具体结果见 [验证记录](docs/VALIDATION.md)。

图集 BGM 需要页面提供可用音频地址，无法保证每条作品都能读取；没有可用 BGM 时仍可保存原图。直播、私密与付费内容不在支持范围。请使用你有权保存的内容。

图文来源规则已修正：经作品归属核验的官方展示图片无需同时存在明确的水印下载对照，仍排除显式水印标记或无法判断的水印开关；不改变签名图片地址，也不把只有下载地址的图片当作展示来源。图片下载不依赖 BGM 加载成功，合成时仍需取得可用音频；本次来源修复不代表所有音频网络错误均已解决。

批量解析时请保持 App 打开，结果逐项显示在首页；视频和图集原图可一键保存。单项与批量保存采用相同来源规则。进程被系统终止后可批量重试未完成解析，目前没有断点续传。
