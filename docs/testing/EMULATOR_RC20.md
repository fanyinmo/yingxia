# 1.2.0-rc20 分享页通用错误恢复验证

2026-10-08，普通APK **1.2.0-rc20 / code40**，40,431,938字节，SHA256 `c0a8422eb43a2240fe31452274e7c5a847bcca5fab9eacd35771971a93bf666a`。Android16/API36官方自建AVD，SwiftShader，同原签名覆盖安装；用户手机未连接。本报告只记录本包实际执行，不迁移rc19的245项为rc20通过。

## 这次问题与证据

用户作品 `7693828705596034314`，标题“galgame版黑暗桃花源，乌有乡到底讲了什么内容？”。手机日志是移动分享页通用错误、无媒体，详情空响应，桌面页没有找到同作品数据。CSP和chrome-extension提示不能单独判断根因：同作品在rc19测试网络下由移动页返回有效媒体并下载55,130,987字节；它不是永久无数据的作品。电脑直连则遇DNS失败，均保留原日志。成功不证明手机当时的通用错误由DNS导致。

`objectKeys`截断可能来自无关对象；当前证据不能把它确定为手机这次失败的唯一原因。受控检查另外证实，普通router/hydration对象第256个字段以后的目标会被旧扫描遗漏，已补充相应覆盖。

## 改动

1. 同作品、页面完整加载、连续三次通用错误且无媒体时，重读原URL一次。与DNS/连接/超时重试共用一次额度，保持原总截止时间；取消移除回调。明确删除、私密、验证码及错误作品不走这种恢复，不改签名地址或媒体归属。
2. 普通视频桌面备用页没有有效媒体时，不因document.complete和八秒水合等待结束而提前终止，继续等待现有总截止时间。目标候选仍需正确归属、有效结构和两次稳定读取；图集已有稳定动态仍可快速完成。
3. 普通路由/实时水合对象每对象最多1024字段，总节点仍12000；RSC保持原256字段扫描和JSON解码中的同作品优先根，避免重复候选。未扩大到无限扫描。
