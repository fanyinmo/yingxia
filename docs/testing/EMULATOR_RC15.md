实际文件专项经生产 ContentDownloader／AlbumDownloader／MediaStore 检查，包括完整 JPEG 与内嵌 MP4 字节、全部 60 帧及 PTS、音轨、选图序号、仅静态封面拒绝、取消回滚。原始用户 JPEG 的两种保存模式保留全部 3,366,772 字节、89 帧及 AAC 数据；这是明确指定本地文件的格式保留验证，不是本次公网解析，也没有把带水印的用户对照文件宣称为无水印来源。原始用户文件未修改。

失败保持记录：单张预览夹具的缩略图没有真实联网加载，测试程序寻找不存在的 Image 描述，且滚动误命中横向图集；两个旧引擎夹具仍断言“下载前拒绝”，与本次“允许读取后验证”的设计不符，其中一个在后台抛 AssertionError 导致进程退出。随后修改夹具为真实可见卡片文字与竖向滚动、允许下载资格后模拟文件校验拒绝；实际静态封面拒绝已由生产下载器专项独立覆盖。修正后的测试必须在后续包重新运行，不能将失败改写为本包全部通过。

本轮终端不同方法合计 49 PASS、3 FAIL；来源、普通界面、文件格式和 OEM 相册验收分开记录。[rc14](EMULATOR_RC14.md) 的结果不移算为本包。源码清单 249 项不是运行通过数。

本地原始证据位于忽略目录：`outputs/reports/emulator-rc11/api36-host-rc15-native14.json`、`api36-host-rc15-user-original-motion-jpeg.json`、`api36-host-rc15-engine102.json`、对应日志与私有取证副本。源审查另外发现 RSC 宽对象／队列预算可遗漏目标数据，后续候选修复并复测；真实 S08 仍未获通过结论。

以上不证明红米相册会识别或播放实况，也不证明 QQ／微信接收后自动播放。正式第三版仍待完整验收，未上传 GitHub。
