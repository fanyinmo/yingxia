## 修复原因与范围

rc12 的移动分享页未向“双子星”“苹果动态循环”“命数如织”提供完整素材；显式桌面组件随后取得“命数如织”的真实逐图片段。rc13 因此在移动页与详情接口均没有可下载数据后，自动检查一次同作品官方桌面图集页，最长 20 秒。只有同作品、可信完整图集与逐图动态资源才进入结果；普通视频、只有 BGM、推荐作品和不可信地址不会被当作已恢复图集。

成功后自动展示解析结果，保存仍由用户选择，不需要再点一次「检查动态资源」。新增守卫覆盖取消、过期回调、宿主离开后重试、需要手动验证、批量失败后继续，以及 API 已有可信素材时不重复读取。真正遇到登录或验证码时仍保留手动验证流程，不自动操作登录或验证码。

## 电脑环境与未验收项

网络验证观察到官方域名多个公开 DNS 地址中的部分连接超时。本轮自有模拟器采用主机公开 DNS 地址择优连接和 **不解密 TLS 的 opaque CONNECT 隧道**，条件标记为 OWN_AVD_HOST_DNS_FAILOVER_TLS_OPAQUE_PROXY；Android 继续校验证书与主机名。未在生产包固定 IP、未替换证书校验、未修改电脑全局代理。不得将同条件下结果写成未辅助网络或红米手机网络已经通过。

rc13 尚未执行完整原手册 246 条、完整 Android 受控回归组及所有导出格式组合。原生 GIF／WebP／APNG、内嵌实况及明确 LIVE／ANIMATED 公网样例仍需逐项补足；DYNAMIC 样例不能替代原生 LIVE 验收。红米原生相册的实况识别、长按播放和分享后保留，QQ／微信实际发送接收及自动播放，本版本均未验收。普通模拟器、MP4 全帧解码与 JPEG/XMP 结构验证不能代替这些设备与客户端结果。
