# 安装与使用

正式第二版为 **影匣 1.1.0（versionCode 20）**，最低 Android 10。在 [GitHub Releases](https://github.com/fanyinmo/yingxia/releases) 下载 `yingxia-1.1.0.apk`，本地构建路径为 `outputs/apk/yingxia-1.1.0.apk`。

正式包沿用原开发签名，可以直接覆盖首版或旧测试版，保留记录、已有文件、外观和保存位置，无需先卸载。用户已确认候选 **1.1.0-rc3 / code 19** 的手机测试正常，正式包采用 **1.1.0 / code 20** 单独构建与校验；候选反馈不是正式 APK 的手机测试记录。首版为 1.0.0，相对变化见 [变更记录](CHANGELOG.md)。

## 视频与图集

1. 从抖音复制分享文案或链接。首页输入为空时点“粘贴并解析”；已有内容时点“解析作品”。App 只在点击粘贴按钮时读取剪贴板。
2. 解析成功后直接预览或下载，不再显示版本选项。输入框右侧叉号清空内容和解析结果；修改链接后需要重新解析。
3. 视频可展开“自定义文件名”再下载，默认存入 `Movies/DouyinDownloads`。
4. 图集可“保存 N 张图片”，默认存入 `Pictures/DouyinDownloads`。读取到 BGM 时，展开“文件名与合成设置”，选择 2–10 秒/张，再将图片与 BGM 合成视频。
5. 在“下载记录”打开完成文件。原图与合成视频可分别保存，已有可读取的相同内容与保存类型会提示重复。

首页、批量添加、文件名、记录搜索和预览秒数等输入框，统一使用与首页一致的 12dp 圆角。

所有下载与预览固定使用同一作品的无水印来源，单链接、批量单项和“保存已解析”遵循相同规则。旧版的版本选择设置不再生效，原有下载记录、文件和其他设置保留；旧的有水印或水印未确认记录不会阻止重新保存。

程序收集同作品的播放与不同清晰度地址，并尝试通过页面给出的媒体编号补全平台播放入口。找到首个有效媒体后结束校验，只有该来源失败时才继续尝试同类备用地址；不会下载有水印或未分类来源来替代。

图集需每一张都有可用的无水印来源才可保存或合成，否则提示解析失败。功能通过选择平台提供的媒体来源实现，不裁切画面，也不处理作者嵌入原画面的文字或标志。

第二版修正了图文来源判断：经确认属于该作品的官方展示图片，无需同时存在明确的水印下载对照地址即可使用；已知水印标记和无法判断的水印开关仍排除。同一图片的不同清晰度按 URI 匹配，保持整套图片顺序，单条与批量规则一致。这是图片来源选择，不能移除作者已经写入图片的 Logo 或文字。

缺少 BGM 或音频加载失败时仍可保存原图；“图片 + BGM 合成视频”需要实际取得可用音频。此次图文来源修改不代表所有音频网络错误均已解决，解析到 BGM 地址也不代表音频已经下载成功。图集上限 100 张，单张 32 MB、图片总计 512 MB、BGM 64 MB；合成最长 15 分钟，单视频不超过 2 GB。

## 视频预览

解析后点击预览，画面保持视频原比例，横竖屏自动调整。下方圆角进度条显示已播放与已缓冲部分；拖动时更新时间，松手跳转。播放按钮居中，两侧提供静音和放大画面。到“设置 → 预览控制”用两个输入框分别设置前进、后退秒数：范围 1–120 秒，默认各 10 秒。输入框下方一行 5／10／15／30／60 秒快捷值，点击后同时设置两个方向；也可继续分别输入。快捷按钮保留完整的圆角描边，普通宽度尽量同时显示全部值；窄屏或大字模式可横向滚动。设置自动保存，重新打开预览时生效，按钮数字同步更新。播放结束后可重播，加载失败时可重试。

打开预览和开始保存时都会重新检查下载来源，来源失败时尝试同类备用地址；检查失败时会显示具体原因。

此前失败视频的跳转目标已确认为抖音冷 CDN 使用的 `bdcgslb.com` 动态子域，第二版已补上合法单层子域的来源规则。可信来源返回 HTTP 重定向时，会先转换为 HTTPS 再请求，仍不发送明文 HTTP。诊断也已修正长 CDN 域名被误脱敏的问题。用户确认候选版手机测试正常，实际测试范围见 [验证记录](VALIDATION.md)。

播放控件跟随主题色。切到后台会暂停，回到前台需手动继续；关闭预览会释放播放器。

## 外观与背景

新安装默认天蓝主题。覆盖更新保留已有外观；可在“设置 → 外观 → 主题色”切换到“天蓝”，或恢复默认外观。

“自选”打开调色盘：拖动色相条选择颜色范围，在渐变区域选择浓淡与明暗。圆形色块显示当前选色，也可点常用色。调整即时预览并保存，无需输入颜色编号。

明暗模式支持浅色、深色、跟随系统。“系统取色”在 Android 12 以上使用系统配色；要显示自己选择的主色，请切换其他明暗模式。主题会调整显示色，保持按钮与文字清晰。

“选择图片”通过系统照片选择器导入背景。选择“完整显示”时才显示上／中／下位置按钮；“铺满裁剪”固定居中，切回完整显示后保留原位置。可调整模糊、暗度和板块不透明度；板块支持 0–100%，文字保护是独立的整页色调层。外观参数使用圆形滑钮与细轨道，调整直接作用于真实页面，已移除独立效果预览板块。“应用柔和融合效果”快速恢复融合参数。App 保存缩放后的私有副本，不修改原图。重开后保留设置，恢复默认外观保留背景；删除背景使用“移除背景”。

## 保存位置、记录与队列

设置中可选择本地子文件夹并授予“使用此文件夹”权限。修改位置只影响之后下载的内容，恢复默认不会移动旧文件。自定义目录是否被系统相册索引取决于手机与文件提供方，可在下载记录中打开。

下载记录支持搜索、排序和多选。“移除记录”保留实际文件，“删除文件”同时删除所选文件和记录；图集包含整组图片。

首页点“批量添加”，粘贴多条链接后加入队列。开始前可长按六点手柄上下拖动，也可点“上移／下移”；左右滑动任务卡可露出移除按钮，移除任务不会删除已保存文件。

处理结束或暂停后，点击批量任务标题旁的“清空全部”并确认，即可清除所有任务和解析结果。单链接输入、已保存文件与下载记录均保留，不需要另解析一个视频来清空列表。处理进行中按钮禁用。

点“解析全部”后自动逐条解析，图集与失败项都不会阻塞后面的链接；每个结果留在首页任务卡中。可以暂停解析，完成后可单项预览、保存，或点“保存已解析”依次保存所有可用结果。批量保存时图集保存原图，需要合成的图集可单独选择“图片 + BGM 合成视频”。

保存过的任务保留解析结果，重复批量保存时会跳过已有可读取的文件。删除文件或移除记录后会重新检查，不再使用旧的重复记录阻止保存。

解析时保持 App 打开，已开始的下载可切换应用。失败项支持“重试未成功”一次重新解析。进程被系统回收后，未保存的临时解析地址需要重查，原任务链接和已保存记录保留。目前不从上次字节位置续传。

## 更新后检查

- 桌面名称为“影匣”，图标为天蓝色；关于页版本为 1.1.0，旧记录和其他设置保留，版本选择已移除。
- 预览视频时检查画面比例、进度拖动、静音、放大和横竖屏布局。
- 调色盘选色、调整圆形滑块后切换三个页面、明暗模式并重开，确认显示与保存正常；背景位置只在完整显示时可选。
- 清空输入，确认旧下载选项随解析结果消失。
- 用自己的视频、图集检查下载画面、图片顺序、合成声音和保存位置；缺少可用来源时应提示失败。图文作品分别检查单条与批量解析、图片保存，合成时确认实际 BGM 可用。
- 在预览控制中分别输入两侧秒数，再点快捷值，确认两个方向同步变化。
- 检查输入框圆角一致、最右侧快捷按钮描边完整；窄屏或大字模式下能滑到所有快捷值。
- 批量加入数条链接，检查拖动、上下移、滑动移除、自动解析、一键保存和清空全部；再次保存应跳过重复文件，清空任务不删除文件和记录。

平台未公开提供作品数据时可能解析失败。已补充图集自身播放地址和官方 audio 元素中的 BGM 来源，但此前真实图集在模拟器仍遇到空数据/HTTP 403；电脑或模拟器的响应不能代替手机结果。手机图文样本已读到图片与 BGM，第二版修正了后续的图片来源拒绝，用户已确认候选测试正常。具体自动测试、手机反馈和正式包检查见 [验证记录](VALIDATION.md)。

遇到失败时，在设置复制问题诊断，并反馈分享链接、提示文字、操作步骤及系统/WebView 版本。诊断会保留跳转目标的域名、协议、端口和校验结果，完整签名地址与 Cookie 不需要提供。
