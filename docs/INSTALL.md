# 安装与使用

本版已移除实况照片保存和动图转实况。保留静图、原格式动图、无声 MP4、GIF、单项保存及 BGM 合成。动态卡片只提供保留动态素材和 GIF；批量保存默认保留已有格式，未分类片段保存为无声动图。旧记录与旧文件保留；读取内嵌动态片段只用于兼容预览或 GIF／BGM 输入，不再生成实况照片。

当前正式版为 **1.2.0 / code 42**，本地安装包与源码位于 `outputs/latest/`，采用用户确认的 rc21 功能。本轮模拟器实际结果及限制见 [电脑验证](testing/EMULATOR_RC21.md) 和 [最新版说明](CURRENT_VERSION.md)。


正式第二版为 **影匣 1.1.0（versionCode 20）**，最低 Android 10。在 [GitHub Releases](https://github.com/fanyinmo/yingxia/releases) 下载 `yingxia-1.1.0.apk`，本地构建路径为 `outputs/apk/yingxia-1.1.0.apk`。

正式包沿用原开发签名，可以直接覆盖首版或 1.1.0 之前的旧测试版，保留记录、已有文件、外观和保存位置，无需先卸载。已安装 1.2.0 候选时，不把正式 1.1.0 当作覆盖升级包。用户已确认候选 **1.1.0-rc3 / code 19** 的手机测试正常，正式包采用 **1.1.0 / code 20** 单独构建与校验；候选反馈不是正式 APK 的手机测试记录。首版为 1.0.0，相对变化见 [变更记录](CHANGELOG.md)。

## 视频与图集

1. 从抖音复制分享文案或链接。首页输入为空时点“粘贴并解析”；已有内容时点“解析作品”。App 只在点击粘贴按钮时读取剪贴板。
2. 解析成功后直接预览或下载，不再显示版本选项。输入框右侧叉号清空内容和解析结果；修改链接后需要重新解析。
3. 视频可展开“自定义文件名”再下载，默认存入 `Movies/DouyinDownloads`。另可“保存 GIF”：展开截取设置，输入起始与时长，精确到 0.1 秒，默认从开头最多 6 秒。最长范围为视频全长，从中间开始时以剩余时长为上限，保存时再次核对实际文件范围。选择“分享”或“清晰”画质，具体限制见下方；两档均无声音，转换不保证原画质。
4. 全静态图集重点显示“保存 N 张图片”，默认存入 `Pictures/DouyinDownloads`。两张及以上可“图片序列合成 GIF”，用每张停留时长控制切换；可设置为 0.1 秒/张，一个 GIF 的单轮时长为所有图片停留时长之和。只有静图时不显示保留动态格式的保存选项。
9. 在“下载记录”打开完成文件。原素材、GIF 和合成视频分别检查重复；修改播放时长或视频 GIF 截取范围后可以重新导出。旧记录缺少时间信息时仍保留，但不会据此阻止保存。

播放时长设置用于 GIF 转换、静图序列 GIF 与 BGM 视频，正常保留动态格式时仍保留原片段时长。序列 GIF 的时间表示每张静图停留多久；逐动态项 GIF 的时间表示这一项动画播放多久，缩短/循环前同样确认。设置中的“静图默认播放时长”支持 0.1–120 秒、0.1 秒精度，自动模式采用此值，图集卡片的统一时长优先。APNG 参与合成时按累计帧时间处理，避免逐帧取整累积漂移。




移动分享页解析失败但作品 ID 已确认时，也可主动检查同 ID 官方桌面页，恢复后再保存；ID 未确认时不能猜作品。遇到真正的网页验证或登录门槛，由用户主动点击“打开抖音验证页面”，在官方页面手动完成后“继续读取”；也可关闭或取消。App 不自动解验证码或登录，常驻登录按钮不算强制门槛。实际公网验证流程仍待单独测试。

## GIF 画质与分享

| 选项 | 最长边 | 最高帧率 | 每帧最多颜色 | 适用 |
| --- | ---: | ---: | ---: | --- |
| 分享（默认） | 480 像素 | 10fps | 128 | 减小体积，尝试用于聊天或表情包 |
| 清晰 | 960 像素 | 30fps | 256 | 保留更多画面细节，体积和处理时间较大 |

两档保持原比例、不放大小来源、无声音，并保留选择的总时长；GIF 延时按 10ms 表示，实际累计时间可能有取整差异。保留总时长不等于保留每个原视频帧。需要原尺寸、帧率与编码画质时，使用原动图文件或无声 MP4。

QQ／微信是否自动播放取决于文件和具体发送入口，不能仅按秒数判断，也不承诺统一的大小门槛。若发送后静止或不能发送，可缩短片段、改用分享档，或保存 MP4。实际体积在导出后显示；分享档仍可能生成较大文件。

首页、批量添加、文件名、记录搜索和预览秒数等输入框，统一使用与首页一致的 12dp 圆角。

所有下载与预览固定使用同一作品的无水印来源，单链接、批量单项和“保存已解析”遵循相同规则。旧版的版本选择设置不再生效，原有下载记录、文件和其他设置保留；旧的有水印或水印未确认记录不会阻止重新保存。

程序收集同作品的播放与不同清晰度地址，并尝试通过页面给出的媒体编号补全平台播放入口。找到首个有效媒体后结束校验，只有该来源失败时才继续尝试同类备用地址；不会下载有水印或未分类来源来替代。

桌面动态图集会优先排列同一张图片自身视频对象及其码率列表中的较高分辨率、帧率、码率、大小来源；未知或相同数据保持原顺序，不修改签名 URL。原始保存保留实际取得的网页文件，不保证与抖音客户端保存文件的码率完全一致。

整套图集保存或合成需要每项都有可用来源；预览中单项保存仅下载所选项，不要求下载其他图片。功能通过选择平台提供的媒体来源实现，不处理作者嵌入原画面的文字或标志；GIF 与视频合成为用户选择的转换。

第二版修正了图文来源判断：经确认属于该作品的官方展示图片，无需同时存在明确的水印下载对照地址即可使用；已知水印标记和无法判断的水印开关仍排除。同一图片的不同清晰度按 URI 匹配，保持整套图片顺序，单条与批量规则一致。这是图片来源选择，不能移除作者已经写入图片的 Logo 或文字。




## 视频预览

解析后点击预览，画面保持视频原比例，横竖屏自动调整。下方圆角进度条显示已播放与已缓冲部分；拖动时更新时间，松手跳转。播放按钮居中，两侧提供静音和放大画面。到“设置 → 预览控制”用两个输入框分别设置前进、后退秒数：范围 1–120 秒，默认各 10 秒。输入框下方一行 5／10／15／30／60 秒快捷值，点击后同时设置两个方向；也可继续分别输入。快捷按钮保留完整的圆角描边，普通宽度尽量同时显示全部值；窄屏或大字模式可横向滚动。设置自动保存，重新打开预览时生效，按钮数字同步更新。播放结束后可重播，加载失败时可重试。

打开预览和开始保存时都会重新检查下载来源，来源失败时尝试同类备用地址；检查失败时会显示具体原因。

此前失败视频的跳转目标已确认为抖音冷 CDN 使用的 `bdcgslb.com` 动态子域，第二版已补上合法单层子域的来源规则。可信来源返回 HTTP 重定向时，会先转换为 HTTPS 再请求，仍不发送明文 HTTP。诊断也已修正长 CDN 域名被误脱敏的问题。用户确认候选版手机测试正常，实际测试范围见 [验证记录](VALIDATION.md)。

rc4 另补充本次视频诊断中 `24898382.ydycdn.com:58001` 的 HTTPS 冷 CDN 节点：仅支持精确的 8 位数字子域与 58001 端口，其他子域、端口、明文 HTTP 和嵌入凭据仍拒绝。这个错误出现在真实视频地址的重定向检查，GIF 转换没有参与该次失败。

播放控件跟随主题色。切到后台会暂停，回到前台需手动继续；关闭预览会释放播放器。GIF／动态 WebP 预览从 App 私有副本读取，复制完成即关闭相册源输入，退出预览清理副本，避免动画播放长期占用相册原文件。

## 外观与背景

新安装默认天蓝主题。覆盖更新保留已有外观；可在“设置 → 外观 → 主题色”切换到“天蓝”，或恢复默认外观。

“自选”打开调色盘：拖动色相条选择颜色范围，在渐变区域选择浓淡与明暗。圆形色块显示当前选色，也可点常用色。调整即时预览并保存，无需输入颜色编号。

明暗模式支持浅色、深色、跟随系统。“系统取色”在 Android 12 以上使用系统配色；要显示自己选择的主色，请切换其他明暗模式。主题会调整显示色，保持按钮与文字清晰。

“选择图片”通过系统照片选择器导入背景。选择“完整显示”时才显示上／中／下位置按钮；“铺满裁剪”固定居中，切回完整显示后保留原位置。可调整模糊、暗度和板块不透明度；板块支持 0–100%，文字保护是独立的整页色调层。外观参数使用圆形滑钮与细轨道，调整直接作用于真实页面，已移除独立效果预览板块。“应用柔和融合效果”快速恢复融合参数。App 保存缩放后的私有副本，不修改原图。重开后保留设置，恢复默认外观保留背景；删除背景使用“移除背景”。

## 保存位置、记录与队列

设置中可选择本地子文件夹并授予“使用此文件夹”权限。修改位置只影响之后下载的内容，恢复默认不会移动旧文件。自定义目录是否被系统相册索引取决于手机与文件提供方，可在下载记录中打开。

下载记录支持搜索、排序和多选。“移除记录”保留实际文件，“删除文件”同时删除所选文件和记录；图集包含整组图片。

首页点“批量添加”，粘贴多条链接后加入队列。开始前可长按六点手柄上下拖动，也可点“上移／下移”；左右滑动任务卡可露出移除按钮，移除任务不会删除已保存文件。

处理结束或暂停后，点击批量任务标题旁的“清空全部”并确认，即可清除所有任务和解析结果。单链接输入、已保存文件与下载记录均保留，不需要另解析一个视频来清空列表。处理进行中按钮禁用。


保存过的任务保留解析结果，重复批量保存时会跳过已有可读取的文件。删除文件或移除记录后会重新检查，不再使用旧的重复记录阻止保存。

解析时保持 App 打开，已开始的下载可切换应用。失败项支持“重试未成功”一次重新解析。进程被系统回收后，未保存的临时解析地址需要重查，原任务链接和已保存记录保留。目前不从上次字节位置续传。

## 更新后检查

- 桌面名称为“影匣”，图标为天蓝色；正式版关于页为 1.1.0，当前候选为 1.2.0-rc21；旧记录和其他设置保留，版本选择已移除。
- 预览视频时检查画面比例、进度拖动、静音、放大和横竖屏布局。
- 调色盘选色、调整圆形滑块后切换三个页面、明暗模式并重开，确认显示与保存正常；背景位置只在完整显示时可选。
- 清空输入，确认旧下载选项随解析结果消失。
- 用自己的视频、图集检查下载画面、图片顺序、合成声音和保存位置；缺少可用来源时应提示失败。图文作品分别检查单条与批量解析、图片保存，合成时确认实际 BGM 可用。
- 检查每张图片的单项保存、混合顺序、0.1 秒静图序列 GIF、完整视频 GIF 范围和 0.1 秒输入；核对动态 BGM 默认时长及自定义截取/循环确认，返回修改不应生成记录或部分文件。
- 图集解析后检查无需额外点击便自动识别动态、动态保存置前、静态封面次级、取消/超时/换链接的旧回调隔离；另测移动失败且 ID 已确认的手动恢复。手机检查仍需独立完成，模拟器通过不保证每条作品和网络都可读取。
- 对同素材分别导出分享和清晰 GIF，核对比例、完整选择时长、实际帧变化、体积及独立重复记录；聊天发送入口的播放单独记录。
- 在预览控制中分别输入两侧秒数，再点快捷值，确认两个方向同步变化。
- 检查输入框圆角一致、最右侧快捷按钮描边完整；窄屏或大字模式下能滑到所有快捷值。
- 批量加入数条链接，检查拖动、上下移、滑动移除、自动解析、一键保存和清空全部；再次保存应跳过重复文件，清空任务不删除文件和记录。

平台未公开提供作品数据时可能解析失败。rc1、rc2 的移动来源曾只返回静态封面或空数据；rc3 已在 MuMu 从同作品官方桌面页取得三条样例的逐图短片并验证真实 GIF，这不保证所有作品或手机环境都可读取。第二版已有的图片来源修正及当时手机反馈保留，具体当前与历史验证范围见 [验证记录](VALIDATION.md)。

遇到失败时，在设置复制问题诊断，并反馈分享链接、提示文字、操作步骤及系统/WebView 版本。诊断会保留跳转目标的域名、协议、端口和校验结果，完整签名地址与 Cookie 不需要提供。
