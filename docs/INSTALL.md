# 安装与使用

**影匣 1.0.0 第一版（versionCode 10）**，本地安装包为 `outputs/apk/yingxia-1.0.0.apk`，最低 Android 10。沿用原开发签名，直接覆盖旧测试版安装，保留记录、已有文件、外观和保存位置，无需先卸载。

## 视频与图集

1. 从抖音复制分享文案或链接。首页输入为空时点“粘贴并解析”；已有内容时点“解析作品”。App 只在点击粘贴按钮时读取剪贴板。
2. 解析成功后可预览并下载。输入框右侧叉号清空内容和解析结果；修改链接后需要重新解析。
3. 视频可展开“自定义文件名”再下载，默认存入 `Movies/DouyinDownloads`。
4. 图集可“保存 N 张图片”，默认存入 `Pictures/DouyinDownloads`。读取到 BGM 时，展开“文件名与合成设置”，选择 2–10 秒/张，再将图片与 BGM 合成视频。
5. 在“下载记录”打开完成文件。原图与合成视频可分别保存，已下载的作品会提示重复。

缺少 BGM 时仍可保存原图。图集上限 100 张，单张 32 MB、图片总计 512 MB、BGM 64 MB；合成最长 15 分钟，单视频不超过 2 GB。

## 外观与背景

新安装默认天蓝主题。覆盖更新保留已有外观；可在“设置 → 外观 → 主题色”切换到“天蓝”，或恢复默认外观。

“自选”打开调色盘：拖动色相条选择颜色范围，在渐变区域选择浓淡与明暗。圆形色块显示当前选色，也可点常用色。调整即时预览并保存，无需输入颜色编号。

明暗模式支持浅色、深色、跟随系统。“系统取色”在 Android 12 以上使用系统配色；要显示自己选择的主色，请切换其他明暗模式。主题会调整显示色，保持按钮与文字清晰。

“选择图片”通过系统照片选择器导入背景。可调整裁切、位置、模糊、暗度和板块不透明度；板块支持 0–100%，文字保护是独立的整页色调层。“应用柔和融合效果”快速恢复融合参数。App 保存缩放后的私有副本，不修改原图。重开后保留设置，恢复默认外观保留背景；删除背景使用“移除背景”。

## 保存位置、记录与队列

设置中可选择本地子文件夹并授予“使用此文件夹”权限。修改位置只影响之后下载的内容，恢复默认不会移动旧文件。自定义目录是否被系统相册索引取决于手机与文件提供方，可在下载记录中打开。

下载记录支持搜索、排序和多选。“移除记录”保留实际文件，“删除文件”同时删除所选文件和记录；图集包含整组图片。

批量队列可加入多条链接，调整等待顺序、移除或重试。遇到图集暂停选择保存方式。已开始的下载可切换应用；解析下一项需要回到 App。强制停止或系统回收可能中断任务，重开后重新解析重试，目前不从上次字节位置续传。

## 更新后检查

- 桌面名称为“影匣”，图标为天蓝色；关于页版本为 1.0.0，旧记录和设置保留。
- 调色盘选色后切换三个页面、明暗模式并重开，确认显示与保存正常。
- 清空输入，确认旧下载选项随解析结果消失。
- 用自己的视频、图集检查下载、图片顺序、合成声音和保存位置。

平台未公开提供作品数据时可能解析失败。已补充图集自身播放地址和官方 audio 元素中的 BGM 来源，但此前真实图集在模拟器仍遇到空数据/HTTP 403，实际 BGM 下载需手机验证。测试范围见 [验证记录](VALIDATION.md)。反馈时可提供分享链接、提示文字、步骤、系统/WebView 版本及设置中复制的问题诊断。
