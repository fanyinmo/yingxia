# 影匣 1.2.0 — 第三版

2026-10-08，versionCode 42。采用用户确认的 1.2.0-rc21 功能版本，正式构建只调整版本名称和编号；Android 10 及以上，沿用原签名，可覆盖旧版保留设置与下载记录。

## 相对 1.1.0 的变化

- **动态素材保存**：图集自动补读同作品的动态来源，按素材显示主要保存操作。原生 GIF／WebP 保留原格式，视频型动图保存为无声 MP4；预览支持单项下载，静态封面为次级操作。
- **GIF 制作**：普通视频可选择完整时长或截取片段，输入精确到 0.1 秒；静态图集可按每张 0.1 秒切换。增加分享／清晰两档，动态 GIF 使用真实运动画面。
- **素材 + BGM 合成**：动态项默认用各自原时长，静图用设置默认值，总时长相加；统一时长可精确到 0.1 秒，缩短取开头、延长循环，保存前提示并确认。
- **解析与传输**：补充官方桌面数据、同作品备用视频来源、受限网络重试和空分享页重读；改善冷 CDN 重定向、分段下载、超时及批量失败后继续处理。
- **使用与外观**：保留批量排序、滑动移除、一键清空，视频预览与进退秒数设置；圆角输入框、圆形滑钮、主题调色盘、背景融合、保存位置与历史记录继续保留。
- **移除实况功能**：不再提供实况照片保存、动图转实况及相关卡片／批量选项。旧文件与历史记录保留，内嵌片段仅用于只读预览或动态转换输入。
