- GIF 记录区分画质档位、截取范围与时长，避免旧导出误拦截不同参数的新导出；结果显示实际体积与发送兼容提示，不承诺 QQ／微信所有入口自动播放。
- 补充同作品 `www.iesdouyin.com/aweme/v1/play/` 官方播放入口候选。所有移动视频候选均遭遇 HTTP 403 时，可受限读取同 ID 官方桌面视频页一次，再通过原有完整媒体检查；不扩大到任意 CDN 或改写签名。

## 1.2.0-rc5 · 分类型保存、单文件实况与动态合成候选（未发布）

`versionCode 25`，相对 rc4 修改：

- 区分静图、动图、实况与类型未明确的动态素材，单条和批量卡片根据内容强调主要保存操作。未知动态素材须选择实况照片、无声动图或 GIF；实况/无声动图选项不改变已知项的类型，主动选择 GIF 则制作兼容动画。静态封面为次级操作。
- 实况改为含 XMP 与原 MP4 的单一 JPEG，下载记录直接读取内嵌片段播放，不再发布照片＋独立 MP4 作为新实况。JPEG 封面保持压缩内容，其他格式封面先转 JPEG、保留尺寸；原 MP4 视频和声音不重新编码。手机系统相册识别仍待红米真机确认。
- 视频型动图导出无声 MP4，复制压缩视频轨、尺寸、比例、时间戳并保留旋转信息；整个文件因去音轨和重封装而不同。GIF／动态 WebP 等原生动图继续保留原文件。
- “检查动态资源”仅更新当前作品的来源，不自动下载或添加记录。移动分享解析失败且作品 ID 已确认时，可手动检查同 ID 官方桌面页，恢复结果后再选择格式保存；逐图身份、单条结果和其他队列作品保持隔离。
- 图集预览可逐张/项下载，保留来源顺序与原图片编号。全静图隐藏动态格式保存选项，两张及以上可制作一个按顺序切换的循环 GIF，单轮时长为各张停留时长之和；混合图集明确选 GIF 时各动态项单独导出、默认采用各自原时长，静图仍保留图片。
- GIF 兼容转换提高为最长边 960 像素、最高 30fps、256 色、无声音；来源更低帧率不强制提高。普通视频 GIF 起始与时长精确到 0.1 秒，最长可覆盖完整视频，从中间开始最长到视频结尾，不再固定限制 15 秒。转换仍有画质损失，源文件与 GIF 各受 2 GiB 上限和设备资源限制。
- GIF 编码改为每帧局部自适应调色板，改善固定颜色映射的损失，并修正压缩字典位宽增长与结束边界。动画转换直接读取 GIF／WebP／APNG 实际帧，按叠加与清除规则还原画面；仍受每帧最多 256 色的格式限制，不宣称无损。
- APNG 帧延时改用累计时间边界换算，修复逐帧取整导致 BGM 合成时长持续漂移的问题；亚毫秒帧不逐帧补成 1ms，并处理零分子/分母边界。受控 300 帧、每帧 1/30 秒保持为 10,000ms。
- GIF／动态 WebP 预览先复制到独占私有缓存，复制后关闭相册源输入；退出预览释放动画、清理副本。修复持续占用 MediaProvider 原文件而使随后清理等待不结束的问题。
- 素材＋BGM 合成使用真实动态片段/动画帧，默认按各段原时长、静图默认时长排列，总时长相加；合成视频独立于正常实况照片保存。增加 0.1–120 秒、0.1 秒精度输入及圆形滑钮，可恢复自动时长；静图按设置停留，动态项短截开头、长循环，先说明“设置时长与素材原时长不同”，可继续或返回修改，不当作错误。BGM 循环至视频结束，原片段音轨不混入合成。
- 每项自定义时长按当前作品或队列项隔离，导出时快照固定；GIF/合成视频重复检查加入时间签名，旧记录时间未知时保留文件和历史，不阻止重新导出。取消/失败只清理本任务输出，不覆盖其他素材文件。

- 天蓝色“影匣”名称与图标，首页、下载记录和设置三个页面。
- 视频与图集解析、预览和保存；有可用音频时在手机上把图片与 BGM 合成视频。
- 自选调色盘、明暗模式、背景图片及虚化、暗度、透明度等设置。
- 自定义保存文件夹和文件名、下载记录搜索排序、重复提示、基本批量队列及上下移动。
- 手机本地解析、下载和合成，前台服务显示下载与合成进度。

本文件描述版本差异，不替代 [实际验证记录](VALIDATION.md)。安装方式见 [INSTALL](INSTALL.md)，发布流程见 [GITHUB](GITHUB.md)。
