# 版本变更

## 1.1.0 · 第二个 Git 版本

正式版本为 **1.1.0 / versionCode 20**，标签 `v1.1.0`，安装包 `yingxia-1.1.0.apk`。用户已确认此前的 **1.1.0-rc3 / code 19** 手机测试正常，并授权本次上传；正式包使用新版本配置重新构建与校验，不将候选包改名发布，也不将候选反馈改写为正式包的手机测试。

以下差异以首个 Git 版本 **1.0.0 / versionCode 10** 为基线整理。期间候选测试包的编号不作为新的正式 Git 版本。

### 批量队列更完整

- 原有队列改为自动连续解析，每项结果集中显示在首页；视频、图集与失败项均不会阻塞后续任务，可暂停解析、恢复或重试未成功项。
- 每张任务卡可单独预览和保存；“保存已解析”按顺序保存可用结果，批量中的图集保存图片，读取到 BGM 的图集仍可单项合成。
- 保留上下移动，增加长按手柄拖动、边缘自动滚动和左右滑动移除；处理中锁定排序。
- 增加“清空全部”及确认提示。暂停或处理结束后可清除任务与解析结果，保留单链接输入、已保存文件和下载记录。
- 保存后的任务保留解析结果；重复保存会检查实际可读取的文件，移除记录或删除文件后可重新保存。

### 视频预览重做

- 使用 Media3 播放器替换首版的原生播放控件，画面保持原比例，横竖屏与放大画面适配，修正旋转纹理和比例处理。
- 增加跟随主题色的进度条、已缓冲进度、拖动时间反馈、静音、重播与错误重试；播放控件提供可达的触摸区域与无障碍描述。
- 设置中分别保存前进与后退秒数，范围 **1–120 秒**，默认各 **10 秒**；一行 **5／10／15／30／60 秒**快捷值同时调整两个方向，窄屏或大字模式可横向滚动。
- 切到后台暂停，返回后由用户继续；关闭预览释放播放器，旋转与恢复时保留播放位置。

### 下载与解析来源统一

- 下载与预览固定使用同作品可确认的 CLEAN 来源，单链接、批量单项和“保存已解析”规则一致，不再显示版本选择。
- 收集不同编码、清晰度与下载字段中的候选地址；仅使用页面给出的确切媒体编号补全平台播放入口，不用数字作品 ID 猜测媒体编号。
- 视频校验只检查 CLEAN 候选，首个有效 MP4 地址确认后即停止；不为比较其他版本额外发起请求。地址过期或传输失败时尝试同类备用来源，不保证固定提速比例。
- 预览与保存前刷新所选地址，保留可用最终 CDN 地址与原平台入口，减少解析地址和实际请求地址脱节的问题。
- 图集展示与下载地址分别收集，不同清晰度变体按同一图片 URI 匹配；每张图都需可确认来源，合成使用相同图片来源。
- 修正图文图片来源分类：已确认属于当前作品的官方展示地址，排除显式水印标记和无法判断的水印开关后可作为 CLEAN 来源，不再要求同时存在明确的水印下载变体。图集仍需每张图片都可用，保持完整顺序及同作品 BGM，单条与批量共用该策略。
- 展示与下载地址相同或仅 fragment 不同时，仅归类 ORIGINAL 与 CLEAN，避免同一真实请求被冲突标签拒绝；仅有未分类下载地址或未标明角色的扁平地址仍不会自动升为 CLEAN，明确的来源标记继续按原规则判定。这里的 CLEAN 是来源角色选择，不代表检测或移除了作者嵌入原图的 Logo、文字。
- 实际请求和重定向检查可信域与来源分类，拒绝已知有水印端点、标记或冲突地址。文件写入、发布或记录阶段失败不再启动备用传输，避免重复文件。

### 外观控件调整

- 分享输入、批量添加、文件名、记录搜索和预览秒数统一采用 **12dp 圆角**。
- 外观参数改为圆形滑钮与细轨道，保留触摸、键盘和无障碍范围操作；移除独立效果预览板块，调整直接作用于实际页面。
- 背景位置按钮只在“完整显示”时出现；“铺满裁剪”居中，切回完整显示保留原位置。

### 来源兼容与诊断

- 兼容抖音冷 CDN 跳转到 `bdcgslb.com` 的动态调度子域，修复合法来源被域名规则拒绝的问题。前缀仅接受单层、1–63 字符的有效 DNS 标签；根域、多层子域、伪后缀、嵌入凭据与非标准端口仍拒绝，直接地址要求 HTTPS，不绕过 TLS。
- 兼容可信来源返回的 HTTP 重定向，包含此次新增的合法调度子域：无嵌入凭据且使用默认或 80 端口时，先改为同域、同原始路径与签名参数的 HTTPS 地址，再验证和请求。初始 HTTP 地址仍拒绝，不发送明文请求；任意未知域名不会因此获准。
- 在目标校验拒绝前记录跳转的域名、协议、端口和校验结果；修复较长的有效 CDN 主机名被不透明字符串规则误脱敏的问题。完整签名地址、查询参数、Cookie 和凭据继续脱敏。
- 改进失败原因与重试提示；缺少可用地址时提示重新解析，取消不会被当作备用来源重试。

### 更新与验证边界

- 覆盖更新保留旧下载记录、文件、外观与保存位置；旧的版本选择偏好不再参与下载决策，未确认或有水印的旧文件不冒充 CLEAN 重复记录。
- 清空任务与移除记录不删除已有文件；实际删除文件仍由下载记录中的明确操作触发。
- 增加来源、备用传输、队列、预览和外观的回归验证；运行测试使用隔离状态与自制素材，真实作品需显式单独测试。
- 首版已有主题调色盘、背景图片、视频和图集保存、本地图集与 BGM 合成、自定义文件夹及下载记录，本轮保留并改进，不列作新增功能。

**手机反馈与验证范围：**此前视频失败样本的第二跳 HTTPS 目标为 `bdcgslb.com` 动态子域，已补充来源规则。本次“中文说唱最高的山：跟风超人”图文诊断已确认图片与 BGM 数据，旧的图片来源分类触发解析拒绝，现已修正这一规则。用户随后确认 **1.1.0-rc3 / code 19** 手机测试正常，第二版据此进入正式发布。用户未提供逐项测试日志，不将该反馈扩写为每条链接、每种保存模式均已验证；正式 **1.1.0 / code 20** 的构建检查另行记录。

此次图文来源修改不代表所有音频 CDN 网络错误均已解决，子资源网络错误不是图片分类拒绝的触发点。图片保存不依赖 BGM 加载成功，合成仍需取得并验证实际音频；不能把 `bgm=true` 等同于声音已下载成功。候选自动测试、手机反馈和正式包检查的具体范围见 [验证记录](VALIDATION.md)。
